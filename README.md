# ✨ Calculator

A modern, interactive desktop calculator built using **Python and Tkinter**, featuring a vibrant interface and essential arithmetic operations.

## 🚀 Features
- Addition, subtraction, multiplication and division
- Clear and backspace options
- Division-by-zero handling
- Simple and colourful GUI

## 🛠️ Built With
- Python
- Tkinter

## ▶️ How to Run
```bash
python colorful_calculator.py
```
